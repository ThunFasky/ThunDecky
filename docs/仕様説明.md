# MyFavMusicBox — プログラム仕様説明

Python + pygame 製のデスクトップ音楽プレイヤー。
ピクセル調フォント・オレンジ基調のレトロUIで、フォルダ内の音声/動画ファイルをジャケット付きカルーセル形式で再生する。
（※画像は読み取れないため、以下はスクリーンショットの内容も含めて文章で記述）

---

## 1. 全体構成・デザイン

- **ウィンドウサイズ**: 600 × 600 px 固定
- **配色**
  - メインカラー `MAIN_COLOR = (255, 174, 0)`（オレンジ）… 文字・UI・枠線すべてこの色
  - 背景 `BG_COLOR = (40, 40, 40)`（ダークグレー）
  - 影 `SHADOW_COLOR = (20, 20, 20)`、`SHADOW_OFFSET = 4`（全要素に右下4pxのドロップシャドウ）
- **フォント**（`resource_path()` で同梱想定）
  - UI/時刻/日付: `x14y20pxScoreDozer.ttf`（ピクセルフォント）
  - 曲タイトル: `PixelMplus12-Bold.ttf`
  - 読み込み失敗時は Meiryo UI / システムデフォルトにフォールバック
- **背景アニメーション**: `GeometricShape` を30個生成。四角・中抜き四角・×印が左下方向（vx=-, vy=+）へゆっくり流れ、画面外に出ると再配置。中央付近（`center_gap=200`）を避けて配置される。

## 2. 画面レイアウト（領域ごとの機能）

### 上部
- **中央**: 時刻（24H表記 `HH:MM`、大きいフォント）＋その下に日付・曜日（`YYYY/MM/DD Ddd`）。`datetime.now()` でリアルタイム更新。
- **左上 ①サイコロ風ボタン（shuffle_btn_rect）**: 曲順をランダムシャッフル（`action_shuffle`）。現在再生中の曲インデックスは維持される。
- **左上 ②リスト風ボタン（reset_btn_rect）**: シャッフルした曲順を元の並び（`original_playlist`）に戻す（`action_reset_order`）。
- **右上 フォルダボタン（folder_button_rect）**: tkinter のダイアログでフォルダを選択し、その中の対応ファイルを読み込む（`load_folder`）。

### 中央（ジャケットカルーセル）
- 現在再生中の曲のジャケットを中央に大きく（`ART_SIZE = 250`）、前後の曲を左右に縮小表示（`spacing=230`、距離に応じて scale を最大0.28縮小）。
- ジャケットの周囲は、**ジャケット画像の四隅の色をサンプリングした4色グラデーション縁取り**で囲む（`create_gradient_frame`：2×2の各ピクセルに四隅色を置いて拡大）。
- 曲移動時は `ease_out_quart` でスライドアニメーション（`ANIM_DURATION = 0.4`）。
- ジャケット下に曲名（拡張子除いたファイル名）を表示。`ART_SIZE` を超える長いタイトルは左へスクロール。
- **曲送り操作**:
  - 画面 **右端をクリック**（X>450, 200<Y<400）／**→キー** → 次の曲
  - 画面 **左端をクリック**（X<150, 200<Y<400）／**←キー** → 前の曲
  - **長押し**（`HOLD_DELAY=0.5s` 経過後 `SCROLL_INTERVAL=0.25s` 間隔）で連続スクロール（音声は遅延ロード）
- **再生中の中央ジャケットをクリック** → ジャケット差し替え機能が起動（画像選択ダイアログ → 画像エディタ → 決定でジャケット切替。詳細は「5. ジャケット差し替え機能」）。

### 下部・左
- **再生/一時停止ボタン（play_button_rect）**: トグル（`toggle_play`）。スペースキーでも可。
- **1曲ループボタン（loop_button_rect）**: `loop_one` をトグル。ONのとき曲終了で同じ曲を再生。
- **シークバー（seek_bar_rect）**: ドラッグ/クリックで再生位置を変更。離した時点の位置から再生し直す。

### 下部・右
- **vol ボタン（vol_button_rect）**: クリックで縦型ボリュームバーを表示/非表示（フェードイン/アウト）。←→キーでも全体音量増減（0.25刻み）。
  - **音量システム【2026-07-14 刷新】**: 全体音量（0〜25、ドラッグ0.05刻み）×曲ごと音量（1〜100%、0.1%刻み、`track_volume_map.json` に永続化）。再生は `pygame.mixer.music`（音量128段階しかなく小音量が量子化で潰れ、ゲイン1/128未満は突然無音）をやめ、専用チャンネルの **`FineMusicChannel`** に変更。⚠️ Sound音量×Channel音量の二段掛けはSDL内部で `(chunk*channel)/128` と整数1個に畳まれ128段階のまま（実測で確認済み）。そのため細かい側は **パンニング（`Channel.set_volume(l,r)`＝Mix_SetPanning、サンプル値を0〜255で直接減衰）** を使い、**Sound音量(0〜128)×パン(0〜255)＝実質約32640段階**。SDLのdiskオーディオドライバで実出力振幅を測定し、小音量全域で誤差1%前後・無音ゾーンなし（下限約-90dB）を確認済み。
  - **スライダーはカーブ配分（`VOLUME_SLIDER_CURVE=2.0`）**: 下半分が小音量域（約0〜25%）を占め、よく使う小音量の追い込みがしやすい。**音量バー上でマウスホイール**すると微調整（曲音量±0.5% / 全体±0.05）。バー外のホイールは従来どおり曲送り。
- **ゴミ箱ボタン（trash_button_rect）**: **現在の曲ファイル自体を `os.remove` で物理削除**（`delete_current_file`）。⚠️ ファイル本体（mp3等）がディスクから消える破壊的操作。削除後はプレイリストから除外し次の曲へ。

## 3. 対応フォーマット

```
.mp3 .mp4 .flac .wav .ogg .m4a .wma .aac .gif
```

- 再生は `pygame.mixer.music` が基本。直接再生できない形式（mp4 / m4a / wma 等）や3秒未満のmp3/flacは、`moviepy` で一時wav（`temp_audio_cache/`）に変換してから再生（`prepare_audio_file`）。
- moviepy 未インストール時は動画・M4A・WMA音声が再生不可（起動時に警告）。

### ジャケット画像の取得元（`get_art_data`）
優先順: ①カスタムサムネイル（`thumb_map`）→ ②埋め込みアート（mp3=ID3/APIC, flac=pictures, m4a=covr）→ ③mp4は約1秒地点のフレームを抽出。
取得後は `ART_SIZE` の正方形に中央クロップし、四隅10px領域の平均色を縁取り用4色として算出。

## 4. 永続化ファイル

| ファイル/フォルダ | 内容 |
|---|---|
| `player_state.json` | 最後のフォルダ・曲インデックス・全体音量・loop_one設定。起動時に復元（`load_state`/`save_state`） |
| `thumb_map.json` | 曲ファイルパス → カスタムサムネイル画像パス の対応表 |
| `track_volume_map.json` | 曲ファイルパス → 曲ごと音量（%）。旧int保存・旧0〜1割合保存とも読み込み互換あり |
| `saved_thumbnails/` | 差し替え用サムネ（500×500 JPEG, ファイル名はパスのMD5ハッシュ） |
| `temp_audio_cache/` | 再生用一時wav。終了時に削除（`cleanup_temp`） |

## 5. ジャケット差し替え機能（曲のサムネイルを任意の画像に変更）

**再生中の中央ジャケットをクリックすると、その曲のジャケット画像を自分の好きな画像に差し替えられる機能。** 流れは以下の通り。

1. **中央ジャケットをクリック** → tkinter のファイル選択ダイアログが開く（`start_crop_mode`、対応形式 `*.jpg / *.jpeg / *.png`）。
2. 画像を選択すると **`mode = "CROP"` に切り替わり、画面内蔵の画像エディタ（クロップ画面）が開く**（`draw_crop_mode`）。
   - **ドラッグ**で画像を移動、**マウスホイール**で拡大/縮小（`crop_scale`）。
   - 画面中央に表示された `ART_SIZE`（250px）の正方形枠が、実際にジャケットとして切り出される範囲。枠外は半透明の黒でマスクされる。
   - 画面上部に操作ガイド `Drag/Scroll. ENTER:Save ESC:Cancel` を表示。
3. **ENTER で決定** → 枠内を切り出して **500×500 JPEG** として `saved_thumbnails/`（ファイル名はパスのMD5ハッシュ）に保存し、`thumb_map` に「曲ファイルパス → 画像パス」を登録（`save_cropped_image`）。`art_cache` をクリアして即座に新ジャケットへ反映され、**プレイヤー画面に戻ると曲のジャケットが切り替わっている**。再生位置は差し替え前の位置を保持したまま再開。
   - **ESC でキャンセル** → 何も保存せずプレイヤー画面へ戻る。

> 差し替えたジャケットは `thumb_map.json` に永続化されるため、次回起動以降も維持される。`get_art_data` の取得優先順でもカスタムサムネイルが最優先される（埋め込みアートより上）。

## 6. 主要な定数（調整用）

```python
SCREEN_SIZE      = (600, 600)
ART_SIZE         = 250          # 中央ジャケットのサイズ
FRAME_GAP        = 5            # ジャケットと縁取りの隙間
FRAME_WIDTH      = 8            # 縁取り幅
ANIM_DURATION    = 0.4          # 曲送りアニメ時間
ACTION_COOLDOWN  = 0.25         # 操作クールダウン
SCROLL_INTERVAL  = 0.25         # 長押し連続スクロール間隔
HOLD_DELAY       = 0.5          # 長押し判定までの時間
AUDIO_LOAD_DELAY = 0.4          # 連続スクロール後の音声ロード遅延
SHADOW_OFFSET    = 4
```

## 7. 実装上の注意点 / 既知の構造

- 音声ロードはスレッド（`start_audio` 内の `_load`）＋ `audio_lock` で排他。曲終了は `MUSIC_END`（`pygame.USEREVENT+1`）イベントで検知。
- 長押しとシングルクリックの判定は `run()` のメインループ冒頭で `press_start_time` を使って区別している。
- `original_playlist`（元の並び）と `playlist`（シャッフル後の並び）を分けて保持し、状態保存時は元順のインデックスで記録する。
- 削除・サムネ保存の前後で `pygame.mixer.music.stop()/unload()` してファイルロックを解放している（`time.sleep(0.1)` で待機）。
